# 🍯 Jenu Gumpu

Jenu Gumpu is a modern Android application developed using **Kotlin** and **Jetpack Compose**.  
The project demonstrates modern Android development practices including UI design, local database integration, and structured application architecture.

---

## 📱 Project Overview

The application is designed to provide a clean and interactive Android experience with:

- Modern UI using Jetpack Compose
- Material Design 3 Components
- Local database management using Room Database
- Efficient Android lifecycle handling
- Scalable project architecture

---

## 🚀 Features

✅ Modern Android UI  
✅ Jetpack Compose Integration  
✅ Room Database Support  
✅ Material 3 Design  
✅ Kotlin-based Development  
✅ Responsive User Interface  
✅ Optimized Performance

## 📥 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Imran0219/jenu-gumpu.git
```

### 2️⃣ Open in Android Studio

* Launch Android Studio
* Click **Open**
* Select the cloned project folder

### 3️⃣ Sync Gradle

Allow Gradle dependencies to download and sync.

### 4️⃣ Run the App

Run the application on:

* Android Emulator
* Physical Android Device
